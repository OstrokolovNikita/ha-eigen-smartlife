# Maintenance and versioning

Keep custom_components and HACS metadata; tag verified versions and update CHANGELOG.md. Existing validation/release workflows remain enabled.

## Rules

1. Record the last working commit before editing.
2. Preserve all confirmed releases and recovery points.
3. Keep successful, unsuccessful and untested changes in the change log.
4. Delete duplicate files only after verifying recovery from Git.
5. Do not change runtime behavior during repository housekeeping.

Policy adopted 2026-10-19.
